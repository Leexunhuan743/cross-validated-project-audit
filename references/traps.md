## 测试与验证

### 测试没有判别力

新测试在修复回退后仍通过，或两条路径触发同一个无关错误。对最关键测试做反事实检查：去掉 guard、恢复旧实现或直接在基线运行，确认它会因目标缺陷失败。

### 测试镜像实现而非生产函数

本地 helper 重写生产算法、mock 绕过真实边界、只测试解析副本。搜索生产入口和调用者；必要时让测试直接调用生产函数或公共咽喉。

### 失败分支被吞掉

`if success { assert }`、宽泛异常捕获、只断言“不崩溃”会把失败当通过。要求显式进入预期分支并断言错误类型、文本或状态。

### 测试代码保活旧风险

新 helper 替代了危险写路径，但旧 full-row writer、导出或 fixture 仍被测试调用。搜索符号引用、exports 和 feature/test-only 编译路径，确认旧路径已删除或安全封装。

## 旧数据与持久化

### 新校验卡死旧数据

修复新增命名或格式规则，又在迁移/rename 路径先校验旧值，导致历史记录永久无法处理。用真实旧记录做迁移测试；旧值应被豁免、先归一化或显式迁移。

### 全行写造成丢失更新

从 T0 快照执行 `UPDATE SET a=?, b=?, c=?`，可能回退并发产生的单调字段。追踪读写时间线；优先字段级更新、版本条件或事务冲突检测。

### “原子”操作在边界间留下半成品

文件/对象先写、metadata 后写，或多表操作无事务/补偿。对每个 I/O 边界注入失败，检查公开内容、临时文件、索引和恢复路径。

## 并发与生命周期

### 关停加固引入无界等待

`Wait()`、channel receive、join 或启动握手没有 timeout/cancellation，卡住的 handler 会让关停永久悬挂。构造被阻塞生产函数并验证有界退出与资源释放。

### 重试不是幂等

部分成功后整批重试会重复副作用、推进版本或掩盖原错误。验证重试分类、幂等 key、已完成前缀和原始错误保留。

### 新激活路径暴露潜伏缺陷

接通旧端点、导出或 UI 路由后，潜伏的时区、序列化、权限或状态缺陷才变得可达。不要仅审新行；沿新可达路径检查既有代码。

## 平台、语言与工具语义

### Windows 路径与 rename 语义

尾点/尾空格可能被 Win32 剥离，保留名与大小写折叠会造成记录/目录分歧；覆盖已存在目录的 rename 行为也不同。用目标 OS 上的真实文件函数验证，不能在 Linux 上静态推断 Windows 结论。

### Unicode 与字节边界

按字符截断可能切断 UTF-8 字节或组合字符；CJK、西里尔、emoji、规范化形式和大小写折叠可能改变匹配。把真实生产函数喂入代表性输入并核对字节/显示/存储三层。

### PowerShell gate 语义误报

`-notmatch`、正则转义子串与相等比较并不等价；版本 `1.4.1` 可能匹配 `1.4.1.0` 的子串。复现原运算符和输入，不要用另一语言的 equality 模拟后下结论。

### Rust shift/overflow 误判

移位量达到或超过位宽才触发相关 panic；被移出的值位通常静默丢弃。区分 runtime-break、defensive-only 与不可达输入，并用实际 build mode 验证。

### 第三方库和 release/debug 差异靠记忆判断

外部 crate/package、优化、panic、编码或 FS 行为可能随版本和配置改变。锁定当前版本，调用真实 API；无法运行时引用对应版本的官方文档并标 `CONDITIONAL`。

## 激活路径、死代码与文档

### 死代码与交付遗漏

新实现存在但未导出、未注册、被旧调用点绕开，或旧危险路径仍可达。搜索入口、exports、路由、注册表、feature flag、生成文件和最终包内容。

### 文档过度声称

README/API/CHANGELOG/计划把条件性行为写成绝对保证，例如把跨进程限制说成所有并发保证。为每个用户可见主张找到生产路径和测试；没有证据就收窄措辞。

### Git 范围“空”被误读

空 commit range 不等于空内容，非空 range 也不等于补丁未合入。分开检查祖先关系、patch 等价和最终 tree diff；参见 `git-scoping.md`。

## 计划与交付

### 计划引用不存在或类型不兼容的 API

计划声称 helper、接口、ID 类型或事务能力已存在。逐项定位定义和调用先例，并制作“主张→证据”表；找不到时不能按事实继续。

### 回滚只撤代码、不撤数据或副作用

删除 endpoint 或回退 commit 不能恢复已迁移数据、公开文件、外部消息或版本推进。要求数据回滚、兼容窗口、补偿或明确不可逆门禁。

### 交付树与计划不一致

代码完成但缺 lockfile、workspace 成员、vendor marker、生成物、export、文档或测试；也可能混入无关文件。对照计划、commit set、name-status 和打包结果逐项核对。
